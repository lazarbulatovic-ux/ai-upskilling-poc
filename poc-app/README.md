## Configuration
Copy \ppsettings.Example.json\ to \ppsettings.Development.json\ and fill in:
- AzureAIFoundry:Endpoint
- AzureAIFoundry:ApiKey
- AzureAIFoundry:DeploymentName
- ConnectionStrings:DefaultConnection
